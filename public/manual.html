진행자 가이드

워크숍 게임 매뉴얼

폰으로 참여하는 사내 워크숍 게임 4종 — 빙고 · 퀴즈 · TMI 주인 찾기 · 밸런스 게임 — 을 준비하고 진행하는 방법입니다. 아이스브레이킹(슬랙 선착순 댓글)은 웹 밖에서 진행해요.

주소 치트시트

모든 주소는 http://<서버 IP>:3000 뒤에 붙입니다. 참가자에겐 허브(/) 하나만 공유하면 돼요.

게임참가자현황판 (빔프로젝터)관리자 (진행자만)
🎯 빙고/bingo.html/board.html/admin.html
⚡ 퀴즈/quiz.html/quiz-board.html/quiz-admin.html
🤫 TMI/tmi.html/tmi-board.html/tmi-admin.html
⚖️ 밸런스/balance.html/balance-board.html/balance-admin.html
🎨 캐치마인드/catchmind.html/catchmind-board.html/catchmind-admin.html
🥷 비밀미션/mission.html/mission-board.html/mission-admin.html
💌 마니또/manito.html/manito-board.html/manito-admin.html
🔮 몰래 예언/prophecy.html/prophecy-board.html/prophecy-admin.html

주소를 외울 필요 없이 진행자 콘솔(/host.html)에서 모든 관리자·현황판을 메뉴로 열 수 있어요. 관리자 페이지는 별도 비밀번호가 없으니 링크를 진행자만 알고 있으면 됩니다.

빠른 시작 (워크숍 당일)

  1. 서버 컴퓨터에서 실행: 
    npm install   # 최초 1회
npm start     # http://localhost:3000
  2. 서버 컴퓨터의 IP 확인 (Mac): ipconfig getifaddr en0
  3. 참가자 전원이 서버와 같은 와이파이에 접속한 뒤, 슬랙에 http://<IP>:3000 공유
  4. 빔프로젝터에는 진행할 게임의 현황판을 띄우기

포트를 바꾸려면 PORT=4000 npm start. 모든 진행 상태는 자동 저장되므로 서버가 꺼졌다 켜져도 이어서 진행됩니다.

🎯 빙고 자유 진행 · 5×5

각자 다른 배치의 빙고판을 받고, 자기에게 해당하는 칸을 자유롭게 칠하는 게임.

준비 (사전)

  1. /admin.html에서 항목을 한 줄에 하나씩 정확히 25개 입력 후 저장
  2. 항목을 바꿨다면 게임 리셋을 눌러야 참가자가 새 항목으로 시작해요

진행

  1. 참가자가 /bingo.html에서 이름 입력 → 자동으로 랜덤 배치판 생성
  2. 해당하는 칸을 탭해서 칠하기 (다시 누르면 해제)
  3. 현황판에 전원의 칠한 칸 수 · 빙고 줄 수가 실시간 정렬 — 빙고 달성자는 금색 하이라이트

우승 기준은 자유 — 예: 3줄 빙고 선착순

팁

  • 항목은 "아침형 인간이다"처럼 본인이 해당 여부를 판단할 수 있는 문장으로.
  • 자율 체크라 양심 게임이에요. 우승자에게 칠한 칸을 소리 내어 검증시키면 그 자체로 토크 콘텐츠가 됩니다.

⚡ 퀴즈 진행자 주도 · 카훗 스타일

진행자가 문제를 열고 닫는 라이브 퀴즈. 빠르게 맞힐수록 유리.

준비 (사전)

  1. /quiz-admin.html에서 문제 등록. 형식: 빈 줄로 문제 구분, 첫 줄이 문제, 다음 줄들이 보기(2~4개), 정답 보기 앞에 * 
    우리 회사 창립연도는?
2019
*2020
2021
2022

진행

  1. 참가자 입장 대기 → ▶ 다음 문제로 공개
  2. 참가자는 문제당 1회 답변 (현황판에 응답 수만 표시, 정답은 비공개)
  3. 충분히 모이면 ✅ 정답 공개 → 채점, 정답·응답 분포·순위 공개
  4. 반복 후 마지막 문제 공개 뒤 한 번 더 ▶ 누르면 최종 순위

정답 +100  ·  빠른 정답 1/2/3등 보너스 +30/+20/+10

팁

  • 공개 직후 응답 분포를 보며 "3번 찍은 6명 누구야?" 하고 리액션 타임을 가지면 좋아요.
  • 회사 내부 문제(창립연도, 최다 배달 메뉴 등)가 일반 상식보다 훨씬 잘 먹힙니다.

🤫 TMI 주인 찾기 사전 수집 · 토크 게임

한 사람의 TMI 3개를 힌트처럼 하나씩 공개하며 다 같이 입으로 주인을 추리하는 게임. 폰 답변·점수 없이 토크로 진행해요.

워크숍 며칠 전에 슬랙에 /tmi.html 링크를 뿌려 TMI를 수집해두세요. 2명 이상 제출하면 시작할 수 있어요. 서버에 테스트 데이터가 있다면 시작 전 관리자에서 "전체 초기화"로 지우세요.

수집 (사전)

  1. 참가자가 /tmi.html에서 이름 + TMI 3개 제출 (다시 제출하면 수정)
  2. 수집 중엔 현황판·관리자에 제출자 이름만 보이고 내용은 절대 노출되지 않아요

진행 (현장)

  1. /tmi-admin.html에서 🚀 게임 시작 → 랜덤 순서로 첫 사람의 힌트 1이 공개돼요 (이후 제출 잠김)
  2. ▶ 다음 버튼 하나로 진행: 힌트 2 → 힌트 3 → 주인 공개 → 다음 사람
  3. 힌트가 나올 때마다 다 같이 소리 내어 추리 — 현황판에 참가자 명단이 후보로 떠 있어요
  4. 주인 공개 순간이 하이라이트! 주인공 인터뷰 타임 추천

팁 & 리셋

  • 힌트 1에서 맞히면 리스펙트 — "몇 번째 힌트에 맞혔나"로 자체 점수를 매겨도 재밌어요.
  • 진행 리셋: 진행만 초기화, 제출물 유지 / 전체 초기화: 제출물까지 삭제 (복구 불가!)

⚖️ 밸런스 게임 A vs B · 피날레 추천

양자택일 투표 후 분포를 짠 하고 공개하는 게임. 준비가 가장 간단해요.

준비

  1. /balance-admin.html에서 한 줄에 라운드 하나, A vs B 형식으로 등록 
    평생 마라탕만 먹기 vs 평생 김치찌개만 먹기
연봉 그대로 주 4일 vs 연봉 1.5배 주 6일

진행

  1. ▶ 다음 라운드 → 참가자가 /balance.html에서 투표 (라운드당 1회)
  2. 투표 중엔 분포가 아무에게도 안 보여요 — 눈치 투표 방지
  3. ✅ 결과 공개 → 분포 퍼센트 바 + 다수파 하이라이트 + 순위

다수파 +10  ·  동률이면 투표자 전원 +10  ·  미투표 0

팁

  • 공개 전에 소수파로 예상되는 사람 지목해서 이유를 물어보면 공개 순간이 더 살아납니다.

🎨 캐치마인드 그리기 링크 방식

진행자가 지목한 사람이 그림+정답을 제출하면, 나머지가 폰으로 정답을 입력해 맞추는 게임.

진행

  1. 참가자가 /catchmind.html에서 이름 입장
  2. 진행자: /catchmind-admin.html에서 그릴 사람 선택 → 🔗 그리기 링크 발급 → 복사해서 그 사람에게 슬랙으로 전달
  3. 그 사람: 링크 열고 정답 단어 입력 + 캔버스에 그림 → 제출 (제출 전엔 아무에게도 안 보여요)
  4. 제출되면 현황판·참가자 폰에 그림 공개 → 폰으로 정답 입력 (무제한, 오답은 피드에 흘러감)
  5. 맞히면 즉시 발표. 아무도 못 맞히면 진행자가 ✅ 정답 공개로 스킵
  6. 다음 라운드 = 다음 사람에게 링크 새로 발급 (링크는 라운드마다 1회용)

맞힌 사람 +100  ·  그린 사람 +50  ·  스킵 시 0

팁

  • 정답 판정은 띄어쓰기·대소문자를 무시해요 ("맥 북" = "맥북").
  • 그림 실력보다 정답 단어 선택이 난이도를 좌우해요 — 사내 용어를 섞으면 재밌습니다.

🥷 비밀미션 워크숍 내내 백그라운드

각자 비밀미션을 받아 워크숍 내내 몰래 수행하고, 다른 사람 미션을 간파해 무효화하는 메타게임. 다른 게임과 동시에 돌아가요.

진행

  1. 진행자: /mission-admin.html에서 미션 등록 (한 줄에 하나, 기본 미션 20개 채우기 버튼 있음)
  2. 참가자 입장 후 게임 시작 → 각자 폰에 비밀미션 배정. 미션 풀은 전원 공개, 누가 뭘 가졌는지만 비밀
  3. 수행 후 폰에서 성공 신고 (+100, 양심 기반 — 공개 때 검증 타임)
  4. 다른 사람 행동이 수상하면 간파: 사람 + 미션을 골라 지목 → 적중 시 그 미션 무효 +50, 오판 -20
  5. 워크숍 끝날 때 전체 공개 → "아까 그게 미션이었어?!" 검증 토크

성공 신고 +100  ·  간파 적중 +50  ·  간파 오판 -20

💌 마니또 비밀 배정 · 대공개

시작하면 "몰래 챙길 사람"이 한 줄 사이클로 비밀 배정. 하루 동안 챙겨주고 마지막에 대공개.

진행

  1. 참가자가 /manito.html에서 입장 (3명 이상). 안내문은 관리자가 선택 입력 — 예: "몰래 칭찬 1번 + 간식 1개"
  2. 진행자가 배정 시작 → 각자 폰에 챙길 사람 표시. 시작 후엔 새 입장 불가 (사이클 고정)
  3. 진행 중 각자 "나를 챙긴 사람" 추측 제출 (공개 전까지 변경 가능)
  4. 마무리에 대공개 → 현황판에 전체 사이클(A → B → C)과 추측 적중자(+100) 발표

팁

  • 비밀미션과 같이 돌리면 하루 종일 서로를 의심하고 관찰하는 그림이 완성됩니다 🤝

🔮 몰래 예언 시작 봉인 · 마무리 대공개

오늘 일어날 일을 각자 몰래 예언해 봉인하고, 마무리에 공개하며 다 같이 판정하는 게임.

진행

  1. 워크숍 시작 때 각자 /prophecy.html에서 예언 1개 제출 — "오늘 누군가 커피를 쏟는다" 류
  2. 진행자가 🔒 봉인 (시작 직후에! 늦게 내면 이미 일어난 일을 적는 반칙 가능)
  3. 마무리에 🔮 대공개 → 진행자가 하나씩 읽으며 다 같이 "됐다/안 됐다" 판정, 관리자에서 ⭕/❌ 마킹
  4. 적중 +100. 몰래 상황을 유도해 적중시키는 자기실현 예언도 인정 😏

공통 규칙 & 알아두기

  • 이름이 곧 신원이에요. 폰을 바꾸거나 브라우저를 닫아도 같은 이름으로 입장하면 자기 판·점수로 복귀합니다. 반대로 말하면 이름이 겹치면 같은 사람으로 취급되니 동명이인은 별명으로 구분해주세요.
  • 새로고침해도 상태가 유지되고, 서버가 재시작돼도 게임별 JSON 파일에서 복원됩니다.
  • 현황판이 잠깐 멈춰 보이면 2초 내 자동 재연결돼요. 계속 멈춰 있으면 새로고침.
  • 게임 4개는 완전히 독립적이라 참가자 명단·점수가 공유되지 않아요. 종합 우승은 진행자가 게임별 순위로 집계하세요.

문제 해결

참가자가 접속이 안 돼요

참가자 폰이 서버 컴퓨터와 같은 와이파이인지 먼저 확인하세요 (사내 게스트망·개인 핫스팟은 분리된 경우가 많아요). 다음으로 서버 컴퓨터 방화벽이 3000 포트를 막고 있는지 확인합니다.

빙고에서 "아직 게임이 준비되지 않았어요"가 떠요

관리자가 항목 25개를 아직 저장하지 않은 상태예요. /admin.html에서 항목을 저장하면 바로 입장할 수 있어요.

퀴즈/밸런스에서 "다음" 버튼이 안 먹어요

문제가 열려 있는 동안엔 다음으로 넘어갈 수 없어요. 먼저 정답 공개(결과 공개)를 눌러 현재 라운드를 닫아주세요.

실수로 리셋을 눌렀어요

리셋은 복구할 수 없어요. 참가자들이 다시 이름을 입력해 입장하면 새 판으로 시작합니다. TMI의 "진행 리셋"은 제출물이 남아 있으니 다시 시작만 누르면 돼요.

새 게임 데이터로 완전히 새로 시작하고 싶어요

서버를 끄고 레포 루트의 data.json, quiz-data.json, balance-data.json, tmi-data.json을 지운 뒤 다시 켜면 완전 초기 상태가 됩니다. 보통은 각 관리자 화면의 리셋 버튼으로 충분해요.

워크숍 게임 웹 · Express + SSE · 상태는 서버의 JSON 파일에 저장 · 소스는 arkive-workshop 레포
