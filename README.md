# 워크숍 게임 웹

사내 워크숍용 게임 허브. 게임: 5x5 빙고, 라이브 퀴즈, TMI 주인 찾기, 밸런스 게임.

## 실행

```bash
npm install
npm start          # http://localhost:3000 (PORT 환경변수로 변경 가능)
```

같은 와이파이의 폰에서 접속하려면 서버 실행한 컴퓨터의 IP로 접속:
`http://<내 IP>:3000`

## 워크숍 진행 순서

### 빙고

1. 진행자: `/admin.html` 에서 빙고 항목 25개 입력 → 저장
2. 진행자: `/board.html` 을 빔프로젝터에 띄우기
3. 참가자: `/bingo.html` 접속(허브 `/` 에서 링크) → 이름 입력 → 해당되는 칸 칠하기
4. 현황판에 인원별 칠한 칸 수 / 빙고 줄 수가 실시간 표시

### 퀴즈 (진행자 주도, 카훗 스타일)

1. 진행자: `/quiz-admin.html` 에서 문제 등록 (빈 줄로 문제 구분, 첫 줄 문제 + 보기 2~4줄, 정답 앞에 `*`)
2. 진행자: `/quiz-board.html` 을 빔프로젝터에 띄우기
3. 참가자: `/quiz.html` 접속 → 이름 입력 → 대기
4. 진행자가 **다음 문제** → 참가자 폰에 보기 표시, 답변은 문제당 1회
5. 진행자가 **정답 공개** → 채점(정답 100점 + 빠른 정답 1/2/3등 보너스 30/20/10) 후 현황판에 정답·응답 분포·순위 표시
6. 마지막 문제 공개 후 **다음 문제** → 최종 순위

### TMI 주인 찾기 (사전 수집 + 현장 토크 게임)

1. 워크숍 전: 참가자들이 `/tmi.html` 에서 이름 + **TMI 3개** 제출 (재제출 시 수정)
2. 현장: 진행자가 `/tmi-admin.html` 에서 **게임 시작** (2명 이상) → 랜덤 순서로 한 사람씩
3. **▶ 다음** 버튼 하나로 진행: 힌트 1 → 2 → 3 → 주인 공개 → 다음 사람. 폰 답변·점수 없이 다 같이 입으로 추리
4. 현황판은 `/tmi-board.html`. 리셋 2종: 진행 리셋(제출물 유지), 전체 초기화

진행자 콘솔(`/host.html`)에서 모든 게임의 관리자·현황판을 메뉴로 열 수 있다.

### 밸런스 게임 (A vs B)

1. 진행자: `/balance-admin.html` 에서 한 줄에 `A vs B` 형식으로 라운드 등록
2. 참가자: `/balance.html` 에서 투표 (라운드당 1회, 투표 중 분포 비공개)
3. 진행자가 **결과 공개** → 분포 공개 + 다수파 +10점 (동률이면 투표자 전원)
4. 현황판은 `/balance-board.html`

## 개발

```bash
npm test    # node --test
```

상태는 게임별 JSON 파일(`data.json`, `quiz-data.json`, `balance-data.json`, `tmi-data.json`)에 저장되어 서버 재시작에도 유지. 새 게임은 각 관리자 화면의 리셋 버튼.
